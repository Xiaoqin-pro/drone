# Standardized benchmark data

Selected Solomon source instances:

```text
r101.txt
c101.txt
rc101.txt
```

The conversion script uses the first 20 customers and creates a single-UAV dynamic instance:

```matlab
BuildStandardizedDynamicBenchmark
```

The converted files are saved under `data/standardized_dynamic`.

The current conversion keeps Solomon customer coordinates, demands, ready times, due dates and service times. Dynamic behavior is generated by hiding the last 20% of customers and revealing them at a fixed event-time fraction. The 3D terrain and obstacle environment remains the project-controlled validation layer.
