# Phase-transition TSPTW pilot data

This directory contains the downloaded n=21 and n=31 compressed instance archives used by `experiments/RunPhaseTransitionPilot.m`.

The archives are kept in compressed form. The extracted working directories are ignored because they contain thousands of files. Extract them into:

```text
data/phase_transition_extracted/n21/
data/phase_transition_extracted/n31/
```

The current pilot is a screening run only. It is not a final paper result; its purpose is to identify a subset whose feasibility boundary can be crossed under the selected evaluation budgets.
